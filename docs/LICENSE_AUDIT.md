# License audit

PulseFlow is Apache-2.0. `scripts/license-audit.mjs` walks the installed dependency graph, classifies each package's license, and fails if any package in the graph has a denied (copyleft or unknown) license. Exceptions are packages used only at build time, which are reported separately. The packages bundled into the desktop app are identified from the build's module manifest (`apps/desktop/dist/bundled-modules.json`). Their license texts go into `THIRD_PARTY_NOTICES.txt`, which ships inside the app. Electron and Chromium notices ship as `LICENSES.chromium.html`.

Machine-readable output: `artifacts/verification/license-audit.json` and the CycloneDX SBOM `artifacts/verification/sbom.cdx.json`.

**Reviewed exceptions:** `lightningcss` and its platform binary are MPL-2.0. Tailwind v4 uses them at build time to compile CSS. They are not bundled or distributed with the app, and MPL-2.0 is file-level copyleft that only applies to distributed, modified MPL files.
